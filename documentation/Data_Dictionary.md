# Data Dictionary

| Column | Meaning |
|---|---|
| Customer ID | Unique customer identifier |
| Customer Name | Customer display name |
| Customer Segment | Behavioral/lifecycle segment |
| Age Group | Customer age band |
| Region | Geographic region |
| Acquisition Channel | Source that brought the customer |
| Campaign Name | Associated marketing campaign |
| Website Visit Date | Visit date |
| Page Views | Number of pages viewed |
| Product Viewed | Product/plan viewed |
| Add to Cart | 1 if added to cart |
| Checkout Started | 1 if checkout started |
| Purchase Completed | 1 if purchased |
| Purchase Value | Revenue generated |
| Session Duration | Session duration in seconds |
| Bounce Status | Whether the visit bounced |
| Customer Feedback Score | Feedback score 1–5 |
| Customer Retention Status | Retained, Churned or Not Applicable |
| Funnel Stage | Current/latest funnel stage |
| Conversion Status | Converted or drop-off |
